## 調達検討・メモ

- **キースイッチ / ソケット**:
  - スイッチ候補: リニア軸（Gateron Yellow, TTC, Akko 等）または 静音リニア軸
  - ホットスワップ対応のため Kailh PCB Sockets (CPG151101S11) を採用予定
- **トラックボール**:
  - [Pimoroni Trackball Module (PIM447)](https://shop.pimoroni.com/products/trackball-breakout) または 光学センサーモジュール (PMW3360等) の比較検証
  - 省電力性およびピン数節約の観点から I2C 通信対応モジュールが有力候補
- **バッテリー周り**:
  - 3.7V LiPoバッテリー（300mAh〜800mAh程度、ケース内寸法とトレードオフ）
  - 充電管理IC（TP4056 または MCP73831 モジュール）
  - 低自己消費電流LDO（XC6206, AP2112K 等）
