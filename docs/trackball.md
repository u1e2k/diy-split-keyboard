# トラックボール インターフェース設計メモ (Trackball Interface Design)

本ドキュメントでは、キーボードに内蔵するトラックボール（または光学式センサー）の通信インターフェース、配線、およびZMKファームウェアでの統合方針をまとめます。

---

## 1. センサー候補の比較検討

| 項目 | Pimoroni Trackball (PIM447) | PMW3360 光学センサーモジュール |
|---|---|---|
| **方式** | ホール効果センサー式 ミニトラックボール | 光学式（ゲーミングマウス用ハイエンド） |
| **通信方式** | **I2C** | **SPI** |
| **必要信号線数** | 4本 (SCL, SDA, INT, GND, VDD) | 6本 (SCK, MOSI, MISO, CS, MOT, GND, VDD) |
| **消費電力** | 非常に小さい（BLEキーボード向け） | 相対的に大きい（常時トラッキング時は数十mA） |
| **省電力スリープ** | モーション検出割込でMCU起床可能 | レジスタ設定によるスリープ制御が必要 |
| **サイズ・機構** | 超小型・薄型（親指キー周りに配置容易） | レンズ・ホルダー・ボール支持機構が必要（大型） |
| **ZMK対応状況** | コミュニティドライバ (zmk-pimoroni-trackball 等) | コミュニティドライバ (zmk-pmw3360 等) |

---

## 2. 接続インターフェースと配線 (I2C採用時)

### 信号線割り当て案
- **VDD**: 3.3V
- **GND**: グランド
- **SCL (I2C Clock)**: P0.11（モジュール側で未実装の場合は 4.7kΩ で 3.3V にプルアップ）
- **SDA (I2C Data)**: P0.12（モジュール側で未実装の場合は 4.7kΩ で 3.3V にプルアップ）
- **INT (Interrupt)**: P0.13（ボール回転検知時の割り込み入力ピン）

> [!TIP]
> I2Cを採用することで、マイコンのGPIO消費を最小限（2〜3ピン）に抑えられ、マトリクス用のピン数を十分に確保できます。

---

## 3. ZMKファームウェア統合方針

- **ドライバモジュール**:
  - ZMKのマニフェスト (`config/west.yml`) に外部モジュール（例: `badjeff/zmk-pimoroni-trackball` 等）を追加
- **デバイスツリー定義 (`.overlay`)**:
  - `&i2c0` または `&i2c1` ノードにトラックボールデバイスを追加
  - クリック操作（スイッチ内蔵時）をキーコードまたはマウスボタン（`&mkp LCLK`）にバインド
- **スクロールモード**:
  - 特定のレイヤーキー（モーメンタリ）を押している間、ボールの動きを垂直・水平スクロールとして解釈するレイヤ設定
