## 2. キーマトリクス構成 (60% Split)

### 左手側 (Left Half)
- **Rows**: 5 (Row 0 〜 4)
- **Cols**: 6 (Col 0 〜 5)
- **ダイオード向き**: Col to Row (ダイオードのカソードをRow側に接続、ZMK標準推奨)

### 右手側 (Right Half)
- **Rows**: 5 (Row 0 〜 4)
- **Cols**: 6〜7 (Col 0 〜 6)
- **トラックボール**: 右手側親指クラスター付近に配置予定

---

## 3. ペリフェラル信号線

### トラックボール (I2C接続時)
- **SCL**: P0.11 (4.7kΩ プルアップ抵抗推奨)
- **SDA**: P0.12 (4.7kΩ プルアップ抵抗推奨)
- **INT (割込)**: P0.13
- **Power**: 3.3V (VDD) / GND

### バッテリー電圧監視 (ADC)
- **分圧回路**: V_BAT -> 820kΩ -> AIN0 (P0.02) -> 820kΩ -> GND (または 1MΩ + 1MΩ)
- **コンデンサ**: ノイズ低減用に ADCピン - GND 間に 10nF〜100nF を推奨
